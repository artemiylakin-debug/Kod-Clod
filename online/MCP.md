# ИИ через MCP

К DATA.OUT можно подключить ИИ-помощника — Claude, ChatGPT или другой клиент с поддержкой
[MCP](https://modelcontextprotocol.io) (Model Context Protocol). Сервер — функция Supabase `mcp`
(`online/mcp.ts`), протокол Streamable HTTP: запросы POST с JSON-RPC, ответы JSON.

Адрес сервера:

```
https://lnkekrusqjdroomcufen.supabase.co/functions/v1/mcp
```

## Что умеет ИИ

Без ключа — только чтение:

| Инструмент | Что делает |
|---|---|
| `level_format` | описание формата уровня: карта из клеток 32×20, символы, враги, боссы, опасности |
| `validate_level` | проверяет уровень так же, как игра, и перечисляет, что исправлено |
| `list_levels` | уровни сообщества: новые или самые любимые |
| `get_level` | один уровень целиком — можно взять за основу |
| `leaderboard` | таблица рекордов по очкам, уровням или побегам |
| `get_player` | профиль игрока по имени |

С ключом игрока — ещё черновики в его аккаунт:

| Инструмент | Что делает |
|---|---|
| `whoami` | чей ключ подключён |
| `save_draft` | кладёт уровень в «Мои уровни» → «От ИИ» (до 30 черновиков) |
| `list_drafts`, `get_draft`, `update_draft`, `delete_draft` | работа с этими черновиками |
| `my_levels` | уровни, которые игрок уже опубликовал |

Опубликовать уровень ИИ не может: игрок открывает черновик в конструкторе карт, проходит его
и публикует сам. Так в сообществе не бывает непроходимых уровней.

## Ключ игрока

В игре: «Аккаунт» → «ИИ через MCP» → «Создать ключ для ИИ». Игра покажет адрес с ключом вида
`…/functions/v1/mcp?key=dok_…` — он виден один раз. Ключ можно передать и заголовком
`Authorization: Bearer dok_…`. В базе хранится только SHA-256 ключа (таблица `mcp_keys`);
у игрока — до 5 ключей, ненужный отзывается там же, на экране «ИИ через MCP».

## Как подключить

- **Claude** (claude.ai и приложение): «Настройки» → «Коннекторы» → «Добавить свой коннектор» → адрес.
- **Claude Code**: `claude mcp add --transport http data-out "<адрес>"`.
- **Другие клиенты**: любой с подключением к MCP по HTTP (Streamable HTTP) — указать адрес.

Потом можно просить, например: «Прочитай формат уровней DATA.OUT и сделай мне симметричную арену
с роутерами и двумя турелями».

## Развернуть функцию заново

`online/mcp.ts` разворачивается как функция `mcp` с **выключенным Verify JWT** (её вызывают
ИИ-клиенты, а не вошедшие игроки). Ключи Supabase функция получает сама. Нужные таблицы
(`mcp_keys`, `level_drafts`) и функцию `mcp_key_create` создаёт `schema.sql`.

Правила карты в `mcp.ts` повторяют игру (`normLevel` и `mapToCfg` в `index.html`) — при правке
формата уровня менять оба места.
