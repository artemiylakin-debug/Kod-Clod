# ИИ через MCP

К DATA.OUT можно подключить ИИ-помощника — Claude, ChatGPT или другой клиент с поддержкой
[MCP](https://modelcontextprotocol.io) (Model Context Protocol). Сервер — функция Supabase `mcp`
(`online/mcp.ts`), протокол Streamable HTTP: запросы POST с JSON-RPC, ответы JSON.

Адрес сервера:

```
https://lnkekrusqjdroomcufen.supabase.co/functions/v1/mcp
```

## Что умеет ИИ

Без ключа — только чтение:

| Инструмент | Что делает |
|---|---|
| `level_format` | описание формата уровня: карта из клеток 32×20, символы, враги, боссы, опасности |
| `validate_level` | проверяет уровень так же, как игра, и перечисляет, что исправлено |
| `list_levels` | уровни сообщества: новые или самые любимые |
| `get_level` | один уровень целиком — можно взять за основу |
| `leaderboard` | таблица рекордов по очкам, уровням или побегам |
| `get_player` | профиль игрока по имени |

С ключом игрока — ещё черновики в его аккаунт:

| Инструмент | Что делает |
|---|---|
| `whoami` | чей ключ подключён |
| `save_draft` | кладёт уровень в «Мои уровни» → «От ИИ» (до 30 черновиков) |
| `list_drafts`, `get_draft`, `update_draft`, `delete_draft` | работа с этими черновиками |
| `my_levels` | уровни, которые игрок уже опубликовал |

Опубликовать уровень ИИ не может: игрок открывает черновик в конструкторе карт, проходит его
и публикует сам. Так в сообществе не бывает непроходимых уровней.

У каждого инструмента в `tools/list` есть пометки `annotations` (их требует каталог приложений ChatGPT):
`readOnlyHint` — у всех, кроме `save_draft`, `update_draft`, `delete_draft`; `destructiveHint` — у `update_draft`
и `delete_draft`; `openWorldHint` — ни у кого (сервер работает только с данными игры).

## Ключ игрока

В игре: «Сообщество» (или «Аккаунт», или вкладка «Готово» конструктора) → «Подключить ИИ» → «Создать ключ».
Игра покажет ключ и адрес вида `…/functions/v1/mcp?key=dok_…` — они видны один раз. Ключ можно передать и заголовком
`Authorization: Bearer dok_…`. В базе хранится только SHA-256 ключа (таблица `mcp_keys`);
у игрока — до 5 ключей, ненужный отзывается там же, на экране «Подключить ИИ».

## Как подключить

В игре экран «Подключить ИИ» устроен как подключение в Figma: шаг 1 — ключ, шаг 2 — карточки клиентов,
под выбранной — свои шаги и кнопки «Копировать» (`AI_CLIENTS`, `aiHow` в `index.html`).

- **Claude** (claude.ai и приложение): «Настроить» → «Коннекторы» → «+» → «Добавить свой коннектор» → адрес
  с ключом, «Без входа». Кнопка в игре открывает https://claude.ai/customize/connectors.
- **Claude Code** — плагин из этого репозитория ([claude-plugin/](../claude-plugin/README.md)):
  `/plugin marketplace add artemiylakin-debug/Kod-Clod`, потом `/plugin install data-out@data-out`; ключ плагин
  спросит сам. Или без плагина: `claude mcp add --transport http data-out "<адрес с ключом>"`.
- **ChatGPT** — режим разработчика, свой коннектор по адресу, без аутентификации; каталог приложений —
  [chatgpt-app/](../chatgpt-app/README.md).
- **Cursor** и **VS Code** — кнопка «в один клик» (ссылки `cursor://anysphere.cursor-deeplink/mcp/install?…`
  и `vscode:mcp/install?…`) или JSON для настроек вручную.
- **Любой чат** (ChatGPT без режима разработчика, Gemini, Алиса…) — без MCP: игра даёт подсказку с правилами карты
  (`aiPrompt`), ответ ИИ вставляется в «Мои уровни» → «Вставить уровень от ИИ» (`lvPaste`, проверка — `normLevel`).
  Работает и в артефакте, где своей базы нет.
- **Другие клиенты**: любой с подключением к MCP по HTTP (Streamable HTTP) — указать адрес.

Потом можно просить, например: «Прочитай формат уровней DATA.OUT и сделай мне симметричную арену
с роутерами и двумя турелями».

## Развернуть функцию заново

Сейчас развёрнута версия 3 (5.11.2026, с пометками `annotations`).
`online/mcp.ts` разворачивается как функция `mcp` с **выключенным Verify JWT** (её вызывают
ИИ-клиенты, а не вошедшие игроки). Ключи Supabase функция получает сама. Нужные таблицы
(`mcp_keys`, `level_drafts`) и функцию `mcp_key_create` создаёт `schema.sql`.

Правила карты в `mcp.ts` повторяют игру (`normLevel` и `mapToCfg` в `index.html`) — при правке
формата уровня менять оба места.
