# DATA.OUT онлайн: вход, рекорды, поддержка игры

Сайт игры: **https://artemiylakin-debug.github.io/Kod-Clod/**

Пока база не настроена, сайт пускает в игру без входа: иначе в неё нельзя было бы играть вовсе.
Когда настройка сделана, **вход обязателен**: каждый, кто открыл ссылку, принимает соглашение
и видит экран входа, а играть можно только с аккаунтом:

- **Войти через VK ID** и **Войти через Яндекс ID**;
- **Войти по логину** / **Создать аккаунт** — свой аккаунт прямо на сайте: логин и пароль,
  без почты, телефона и сторонних компаний.

Игроки получают прогресс на любом устройстве и место в общей таблице рекордов. Прогресс,
набранный в браузере до входа, переходит в аккаунт. Если сервер временно недоступен, игрок,
который уже входил на этом устройстве, играет дальше — прогресс досохранится, когда связь вернётся.
Новый игрок без связи с сервером войти не сможет.

Аккаунты и рекорды хранятся в **Supabase** — бесплатной облачной базе (карта не нужна).
Для VK ID, Яндекс ID и регистрации на сайте в проекте есть небольшая серверная функция
`online/ru-login.ts`. Google и Apple можно добавить позже (шаги 5 и 6).

> **Про ключи.** В `online-config.js` пишутся только открытые значения (адрес проекта,
> ключ `anon public`, ID приложений) — их и так видит любой, кто откроет сайт.
> Секретные ключи (Client secret Яндекса и Google, ключ `service_role`/`secret` Supabase)
> вводи только в настройках Supabase. Не вставляй их в файлы репозитория и не присылай в чат.

**Порядок:** шаги 1, 2 и 7 — и уже работают аккаунты на сайте. Потом шаги 3 и 4
добавят VK ID и Яндекс ID, а шаг 8 — поддержку игры через ЮMoney.

**Быстрый путь — скрипт.** Шаги 1, 2 и 7 умеет делать `online/setup-supabase.mjs`: он создаёт
проект, таблицы, функции, адрес сайта и вписывает настройки в `online-config.js`. Нужны
аккаунт на supabase.com (можно войти через GitHub) и токен доступа со страницы
**supabase.com/dashboard/account/tokens**. Запуск: `SUPABASE_ACCESS_TOKEN=… node online/setup-supabase.mjs`
(Node.js 18+). Токен даёт доступ ко всему аккаунту Supabase: не публикуй его и удали после настройки.

**Если база уже создана** по прошлой версии этой инструкции: запусти `online/schema.sql`
ещё раз (шаг 1.2) — он добавит место для 200 уровней, облика, битов, профилей и уровней
сообщества, ничего не стирая.

## 1. Supabase — база и аккаунты

1. Зарегистрируйся на **supabase.com** → **New project**. Название — `data-out`, пароль базы
   придумай и сохрани у себя, регион — ближайший к игрокам (например, Frankfurt).
2. **SQL Editor → New query** → вставь весь файл `online/schema.sql` → **Run**.
   Появятся таблицы `progress` (прогресс, облик, биты и рекорды), `supporters` и `donations`
   (поддержка игры, шаг 8).
3. **Authentication → URL Configuration**:
   - **Site URL**: `https://artemiylakin-debug.github.io/Kod-Clod/`
   - **Redirect URLs** → Add URL: `https://artemiylakin-debug.github.io/Kod-Clod/`
4. **Authentication → Sign In / Providers → Email** — должен быть включён: по нему входят
   аккаунты на сайте, и через него функция `ru-login` заводит игроков из VK и Яндекса.
   Писем никто не получает, поэтому «Confirm email» можно не трогать: функция сама
   подтверждает аккаунты, которые создаёт.
5. **Project Settings → API Keys** (или **Data API**): скопируй
   - **Project URL** — вида `https://abcd1234.supabase.co`;
   - ключ **anon public** (у новых проектов он может называться **publishable**).

   Впиши оба в `online-config.js` → `supabaseUrl` и `supabaseKey`.

## 2. Функция ru-login (регистрация на сайте, VK ID и Яндекс ID)

1. **Edge Functions → Deploy a new function → Via Editor**.
2. Имя функции: `ru-login`. Сотри пример и вставь весь файл `online/ru-login.ts` → **Deploy**.
3. В настройках функции выключи **Verify JWT** (Enforce JWT verification) → Save.
4. **Edge Functions → Secrets** → добавь `SITE_ORIGIN` = `https://artemiylakin-debug.github.io`.
   Остальные секреты (`VK_APP_ID`, `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`) — на шагах 3 и 4.

Если функцию обновили (новая версия `ru-login.ts` в репозитории) — открой её в Supabase,
вставь файл заново и нажми **Deploy**.

## 3. VK ID

1. Открой **id.vk.com/about/business** → войди → **Создать приложение**.
2. Платформа — **Web**. Название — `DATA.OUT`.
3. **Базовый домен**: `artemiylakin-debug.github.io`
4. **Доверенный Redirect URL**: `https://artemiylakin-debug.github.io/Kod-Clod/`
5. Скопируй **ID приложения** → `online-config.js` → `vkAppId` и в секрет функции `VK_APP_ID`.

## 4. Яндекс ID

1. Открой **oauth.yandex.ru** → **Создать приложение** (тип — для веб-сервисов).
2. Права (доступы): **«Доступ к логину, имени и фамилии, полу»**.
3. **Redirect URI**: `https://artemiylakin-debug.github.io/Kod-Clod/`
4. Скопируй **ClientID** → `online-config.js` → `yandexClientId` и в секрет `YANDEX_CLIENT_ID`.
5. **Client secret** → только в секрет `YANDEX_CLIENT_SECRET`.

## 5. Google (позже)

1. Открой **console.cloud.google.com** → создай проект `DATA.OUT`.
2. **APIs & Services → OAuth consent screen** (Google Auth Platform): тип **External**,
   название `DATA.OUT`, почта для связи — твоя. Опубликуй приложение (**Publish app**),
   иначе войти смогут только тестовые пользователи.
3. **Credentials → Create credentials → OAuth client ID → Web application**:
   - **Authorized JavaScript origins**: `https://artemiylakin-debug.github.io`
   - **Authorized redirect URIs**: `https://ТВОЙ-ПРОЕКТ.supabase.co/auth/v1/callback`
     (точный адрес Supabase показывает на странице провайдера Google, шаг 4).
4. В Supabase: **Authentication → Sign In / Providers → Google** → включи, вставь
   **Client ID** и **Client secret** → Save.
5. В `online-config.js` поставь `google: true` — на экране входа появится кнопка Google.

## 6. Apple (по желанию)

Нужен платный аккаунт разработчика Apple (Apple Developer Program, $99 в год).
Если он есть: в Supabase **Authentication → Providers → Apple** есть пошаговая инструкция,
после неё поставь `apple: true` в `online-config.js`.

Отдельного входа через Samsung, Xiaomi, Huawei или Honor нет: эти компании не дают простой
вход для сайтов. Владельцы Android-телефонов могут войти через VK ID, Яндекс ID, логин на
сайте или Google.

## 7. Включить на сайте

Отредактируй `online-config.js` прямо на GitHub (значок карандаша → **Commit changes**).
Через минуту GitHub Pages обновит сайт. Проверь:

1. Открой сайт — сначала игра попросит принять пользовательское соглашение, затем появится экран входа. Кнопки VK и Яндекса видны, только когда в
   `online-config.js` вписаны их ID.
2. **Создать аккаунт** → придумай логин и пароль → **Создать и войти**. Это заодно проверка,
   что Supabase открывается: сделай её **без VPN** — если аккаунт создался, сервер доступен
   игрокам из России.
3. Сыграй уровень, проиграй — в **Рекордах** появится твоя строка (имя по умолчанию — логин,
   поменять его можно в **Аккаунте**).
4. Открой сайт на другом устройстве и войди тем же способом — уровни и облик подтянутся.

Если вход не проходит, текст ошибки показывается на экране входа. Частые причины:

- «Нет связи с сервером» — Supabase недоступен из этой сети (проверь с VPN и без) или
  неверно вписан `supabaseUrl`;
- «Не получилось: …» при создании аккаунта — функция `ru-login` не развёрнута, у неё не
  выключен Verify JWT или неверный `SITE_ORIGIN`;
- VK или Яндекс пишут об ошибке адреса — Redirect URL не совпадает с адресом сайта до символа
  (важна косая черта в конце).

Пароли аккаунтов на сайте восстановить нельзя: почты у них нет. Забывший пароль игрок
просто создаёт новый аккаунт.

## 8. Поддержка игры через ЮMoney

Игра бесплатная: уровни открываются игрой, облик — битами. Поддержка — по желанию игрока.
В благодарность игра открывает набор «Поддержка» (цвета ПЛАТИНА, РУБИН и АЛМАЗ, форма ЩИТ,
следы ЗОЛОТАЯ ПЫЛЬ и СЕРДЕЧКИ, аксессуары КОРОНА, КРЫЛЬЯ и ОРЕОЛ ЗВЁЗД)
и ставит ★ у имени в рекордах. На прохождение поддержка не влияет.

Как это работает: игрок нажимает **Поддержать игру**, выбирает сумму и платит на сайте
ЮMoney картой или кошельком. ЮMoney присылает уведомление функции `yoomoney-hook`, она
проверяет подпись уведомления и отмечает игрока. Данные карты игра не видит.

1. Заведи кошелёк на **yoomoney.ru**. Посмотри в настройках кошелька, какие у него лимиты
   на приём денег: для приёма с банковских карт ЮMoney может попросить подтвердить личность.
2. В Supabase: **Edge Functions → Deploy a new function → Via Editor**, имя `yoomoney-hook`,
   вставь весь файл `online/yoomoney-hook.ts` → **Deploy**. Выключи **Verify JWT** → Save.
3. Открой **yoomoney.ru/transfer/myservices/http-notification** (Настройки → Уведомления):
   - **Куда отправлять**: `https://ТВОЙ-ПРОЕКТ.supabase.co/functions/v1/yoomoney-hook`
   - включи отправку HTTP-уведомлений;
   - скопируй **Секрет для проверки подлинности** → в Supabase **Edge Functions → Secrets**
     добавь `YOOMONEY_SECRET` с этим значением;
   - нажми **Протестировать** — ЮMoney должен показать, что сервер ответил успешно.
4. В `online-config.js` впиши номер кошелька в `yoomoney` (15–16 цифр, начинается с `4100`).
   Номер кошелька — открытое значение, его видит каждый, кто платит.
5. По желанию: в `donateUrl` можно вписать ссылку на страницу поддержки на другом сервисе
   (Boosty, CloudTips). Там поддержка проходит без набора: эти сервисы не сообщают игре,
   кто поддержал.
6. Проверь: войди в игру → **Поддержать игру** → небольшая сумма. После оплаты ЮMoney вернёт
   на сайт, и через минуту в «Облике» откроется набор, а в рекордах появится ★.

Деньги приходят на твой кошелёк. Если поддержка станет регулярным доходом, по закону её
нужно оформлять (например, как самозанятость) — это стоит учесть и в пользовательском соглашении.

## 9. Сообщество и админ-панель

Всё нужное создаёт `schema.sql`:

- `levels` — уровни игроков из редактора. Публиковать может только вошедший игрок, не больше
  30 уровней на аккаунт; автора, дату и счётчики ставит сама база.
- `level_likes` и `level_plays` — лайки и запуски, по одному на игрока и уровень. Свой уровень
  не лайкнуть и своими запусками не накрутить.
- `progress.bio` — описание «о себе» в профиле, `progress.hidden` — игрок скрыт администратором.
- `admins` — администраторы игры. Им видна кнопка **Админ-панель**: сводка, все аккаунты,
  уровни сообщества, платежи; можно скрыть игрока вместе с его уровнями, стереть описание,
  скрыть или удалить уровень, выдать или забрать ★.

Список администраторов правится только в SQL Editor (из игры — никак). Добавить:

```sql
insert into public.admins (user_id)
select id from auth.users where email = 'логин@player.data-out.app';
```

Для логина с русскими буквами или пробелами адрес другой — проще найти игрока в Table Editor
(таблица `progress`, столбец `name`) и вставить его `user_id`. Убрать администратора:
`delete from public.admins where user_id = '…';`.

## 10. ИИ через MCP

Функция `mcp` (`online/mcp.ts`) — сервер MCP для ИИ-помощников: без ключа он даёт читать уровни,
рекорды и профили, с ключом игрока — складывать ему черновики уровней. Развернуть её так же, как
`ru-login`, с **выключенным Verify JWT**. Таблицы `mcp_keys` и `level_drafts` и функцию
`mcp_key_create` создаёт `schema.sql`. Как подключить ИИ — [MCP.md](MCP.md).

## 11. Гонка (мультиплеер)

Гонке не нужны ни таблицы, ни функции: игроки связываются через Supabase Realtime — публичные
каналы `dataout-lobby` (поиск случайного соперника) и `dataout-race-<код>` (комната на двоих), только
broadcast и presence. Работает с ключом `anon`, если в настройках Realtime проекта разрешены публичные
каналы (так по умолчанию). На бесплатном тарифе действуют лимиты Realtime — 200 одновременных
подключений и 2 млн сообщений в месяц; гонка шлёт по 5 сообщений в секунду от каждого игрока, то есть
около 1 200 за минуту гонки вдвоём. Гонка не открывает уровней и не даёт ни рекорда, ни бит.
