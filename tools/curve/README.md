# Кривая сложности (`LV_K` в `index.html`)

У каждого официального уровня есть множитель опасности `k` (массив `LV_K`, применяет `diffAt` через `D()`).
Его подбирает бот с человеческой реакцией (`botcal.js`: решает раз в 0,2 с, ведёт джойстик неточно,
рывок — не всегда) так, чтобы попаданий за попытку становилось больше ровно с номером уровня:
на «Лёгкой» от 0,25 на уровне 1 до 2,2 на уровне 500 (в замере жизни бесконечные — считаются все попадания).

Нужен Node с Playwright и Chromium. Порядок:

```sh
tools/curve/prepare.sh /tmp/curve-work && cd /tmp/curve-work
# замер всех 500 уровней с текущими k (или KALL=1 — «как задуманы»), 16–24 сида
INF=1 SEEDS='[11,23,47,...]' KMAP=k.json curve/run.sh it0 easy
# шаг подбора: k по промаху мимо цели (с затуханием); повторять 4–5 раз, сиды чередовать
python3 curve/iter.py k.json it0 k1.json 0.25 2.2
# проверка на сидах, которых подбор не видел: два независимых замера и сравнение
python3 curve/verify.py A B 0.25 2.2 && python3 curve/compare.py curve/oA+oB.H.json curve/A+B.H.json
```

`k.json` — список из 500 чисел; текущий берётся из `LV_K`. Итоговые k — среднее (геометрическое)
последних трёх итераций. Новые уровни без замера получают k=1 (уровень как задуман).
