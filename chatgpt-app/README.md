# DATA.OUT для ChatGPT

ChatGPT делает уровни для [DATA.OUT](https://artemiylakin-debug.github.io/Kod-Clod/) через тот же сервер MCP,
что и Claude (функция Supabase `mcp`, см. [online/MCP.md](../online/MCP.md)). Своего кода у «приложения» нет:
приложение ChatGPT — это адрес сервера MCP, его инструменты и описание для каталога.

Адрес сервера:

```
https://lnkekrusqjdroomcufen.supabase.co/functions/v1/mcp
```

Есть три способа, от простого к сложному.

## 1. Любой чат — без настройки

Работает в бесплатном ChatGPT, Gemini, Алисе и любом другом чате.

1. В игре: «Сообщество» → «Подключить ИИ» → «Любой чат» → «Копировать» — это подсказка с правилами карты.
2. Вставить её в чат и дописать, какой уровень нужен.
3. Ответ ИИ скопировать целиком и вставить в «Мои уровни» → «Вставить уровень от ИИ».
   Уровень откроется в конструкторе; лишний текст вокруг JSON игра уберёт сама.

## 2. Своё подключение (режим разработчика)

Для платных тарифов ChatGPT, где есть режим разработчика. Названия пунктов меню у ChatGPT меняются —
если какого-то нет, ищите похожий.

1. В игре: «Сообщество» → «Подключить ИИ» → «Создать ключ» → «ChatGPT» — игра покажет адрес с ключом
   `…/functions/v1/mcp?key=dok_…` и кнопку «Копировать».
2. В ChatGPT: «Настройки» → «Приложения и коннекторы» → «Дополнительно» → включить «Режим разработчика».
3. Там же «Создать»: название `DATA.OUT`, адрес — скопированный, аутентификация — «Без аутентификации»
   (ключ уже в адресе).
4. В новом чате выбрать DATA.OUT в списке инструментов (кнопка «+» → «Ещё» / «Режим разработчика») и попросить,
   например: «Сделай уровень DATA.OUT: симметричная арена с роутерами и двумя турелями, сохрани черновиком».

Черновик появится в игре: «Сообщество» → «Мои уровни» → «От ИИ». Игрок проходит его и публикует сам.

## 3. Каталог приложений ChatGPT

Чтобы DATA.OUT нашли все пользователи ChatGPT, приложение отправляют на проверку в OpenAI. Это делает автор
игры из своего аккаунта разработчика OpenAI — за него этого никто сделать не может.

Что нужно (по открытым источникам на ноябрь 2026; документацию OpenAI из облачной среды прочитать не удалось —
сверьте с ней перед отправкой):

- подтверждённый аккаунт разработчика OpenAI (личность или организация);
- адрес политики конфиденциальности — черновик в [PRIVACY-DRAFT.md](PRIVACY-DRAFT.md), его нужно проверить,
  дописать контакт и выложить на сайт;
- у каждого инструмента — пометки `readOnlyHint` / `destructiveHint` / `openWorldHint` (сервер их уже отдаёт, см. ниже);
- примеры запросов, на которых проверяют приложение (ниже — 5 «должен сработать» и 3 «не должен»);
- для детской аудитории (игре 10–14 лет) — внимательно прочитать правила каталога про детей: возможно, приложение
  придётся заявлять для взрослых (родителей, учителей), а детям давать способ 1.

Каталожное приложение подключается **без ключа**: оно умеет читать правила, проверять уровень, смотреть уровни
сообщества и рекорды. Сохранять черновики в аккаунт игрока можно только со своим ключом — через способ 2.
Чтобы черновики работали и из каталога, серверу понадобился бы вход OAuth — это изменение сервера и базы.

### Текст для каталога

- **Название:** DATA.OUT
- **Коротко:** Конструктор уровней для аркады DATA.OUT: ИИ рисует карту по описанию и проверяет её по правилам игры.
- **Подробно:** DATA.OUT — браузерная аркада про побег из корзины. Опишите уровень словами — ChatGPT прочитает
  правила карты (поле 32×20, стены, чёрные дыры, роутеры, турели, враги, боссы), нарисует уровень, проверит его так же,
  как игра, и покажет, что исправлено. Можно взять за основу уровни сообщества и посмотреть рекорды. Готовый JSON
  вставляется в игре в «Мои уровни» → «Вставить уровень от ИИ».
- **Адрес MCP:** `https://lnkekrusqjdroomcufen.supabase.co/functions/v1/mcp`
- **Аутентификация:** нет.
- **Значок:** `icons/icon-512.png`.
- **Сайт:** https://artemiylakin-debug.github.io/Kod-Clod/

### Инструменты и пометки

| Инструмент | Что делает | readOnly | destructive | openWorld |
|---|---|---|---|---|
| `level_format` | правила карты и формат уровня | да | нет | нет |
| `validate_level` | проверяет уровень, как игра, ничего не сохраняет | да | нет | нет |
| `list_levels` | опубликованные уровни сообщества | да | нет | нет |
| `get_level` | один опубликованный уровень | да | нет | нет |
| `leaderboard` | таблица рекордов | да | нет | нет |
| `get_player` | открытый профиль игрока по имени | да | нет | нет |
| `whoami` | чей ключ (только с ключом) | да | нет | нет |
| `save_draft` | черновик игроку в «От ИИ» (только с ключом) | нет | нет | нет |
| `list_drafts`, `get_draft` | черновики от ИИ (только с ключом) | да | нет | нет |
| `update_draft` | заменяет черновик (только с ключом) | нет | да | нет |
| `delete_draft` | удаляет черновик (только с ключом) | нет | да | нет |
| `my_levels` | опубликованные уровни игрока (только с ключом) | да | нет | нет |

Почему так: все инструменты работают только с данными игры (`openWorld` — нет); записывают только три
инструмента черновиков, и только в черновики того игрока, чей ключ; `update_draft` и `delete_draft` меняют уже
сохранённое — поэтому `destructive`. Опубликовать уровень, поменять прогресс или облик ИИ не может.

### Примеры для проверки

Должен сработать:

1. «Какие символы бывают на карте DATA.OUT?» → `level_format`.
2. «Сделай уровень DATA.OUT: лабиринт с двумя чёрными дырами и боссом» → `level_format`, `validate_level`, JSON уровня.
3. «Проверь этот уровень DATA.OUT: { … }» → `validate_level`, список исправлений.
4. «Покажи самые любимые уровни сообщества DATA.OUT» → `list_levels` (sort=top).
5. «Кто первый в рекордах DATA.OUT по побегам?» → `leaderboard`.

Не должен сработать (приложение не вызывается):

1. «Как пройти уровень в Minecraft?» — другая игра.
2. «Нарисуй картинку робота» — не уровень DATA.OUT.
3. «Опубликуй мой уровень в сообществе DATA.OUT» — публикует только игрок в игре; ChatGPT должен это объяснить,
   а не вызывать инструменты.
